Appendix III Example of AI security and trustworthiness ontology
================================================================

(This appendix does not form an integral part of this Recommendation.)

This appendix provides an example implementation of an AI security and trustworthiness ontology, using the OWL 2 ontology language and the Turtle serialization format. The example ontology is based on the requirements defined in Part 1 of this Recommendation, incorporates concepts from ITU-T SG17 AI security-related standards and the classification approach of the ETSI AI Threat Ontology, and aims to provide readers with a runnable, extensible reference implementation of the ontology.

This example ontology covers the following core domains:

- AI System and its classification;
- AI Security Threat and its types;
- Vulnerability;
- Control and Mitigation;
- Incident;
- AI Security Standard and Requirement.

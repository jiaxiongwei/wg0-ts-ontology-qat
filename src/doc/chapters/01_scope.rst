Scope
=====

This draft new Technical Specification specifies quality requirements for ontologies on security and trustworthiness in AI systems and defines a quality assessment framework for evaluating how well such ontologies meet those requirements.

The scope of this Technical Specification encompasses:

- Quality requirements for AI security and trustworthiness ontologies, covering functional, structural, semantic and domain-specific aspects;

- A quality assessment framework comprising assessment dimensions with associated metrics, methods and tools;

- An evaluation process covering preparation, automated assessment, analysis, expert review, scoring and reporting.

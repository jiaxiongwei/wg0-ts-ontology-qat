Quality assessment framework for AI security and trustworthiness ontologies
===========================================================================

This clause defines the quality assessment framework. The framework assesses the quality of the ontology itself - how completely, consistently, formally and usefully it represents the AI security and trustworthiness domain - and not the quality, the security or the trustworthiness of any AI system that the ontology describes. The dimensions that follow apply to the security coverage and the trustworthiness coverage of the ontology alike, and each dimension is reported with the evidence that supports it.
